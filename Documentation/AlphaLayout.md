# The alpha layout

An opt-in redesign of the shell, next to today's layout: dark only, a top
bar, a left rail, one docked panel and the preview as a card with a
floating action bar. Users switch in the user menu ("Try the new layout
(alpha)") and back in the account menu; the choice is the `studio.layout`
user preference (`classic` | `alpha`), served in the boot config as
`layout`.

The design is work in progress (Paper file "Neos Studio", frames R3-R9).

## Where it lives

- `src/features/shell-alpha/`: the shell (`AlphaShell`), `TopBar`, `Rail`,
  `ActionBar`, primitives and icons, and `shell-alpha.css`.
- `src/lib/layoutMode.ts`: the switch.
- `src/features/preview/chromeStore.ts` and `src/guest/chrome.ts`: what the
  shell asks of the preview - minimal in-page chrome (no element handle, no
  "+" buttons, a thin selection outline), scroll space under the bar, the
  insert line of the Add menu, the device width - and the guest's scroll and
  pointer reports that fade the bar.

Panels come from the panel registry, plugin panels included: main-region
panels are the rail's modes, the others its panel buttons, docked one at a
time. The Documents panel is the page tree dropdown, the Inspector the
"Open full inspector" target of the settings tray, whose fields are the
Inspector's own (`InspectorPanel trayGroup`). Header actions sit in the top
bar, node actions in the node pill's "more" menu.

## Editing (the "Candidate" frames)

Selecting an element opens the settings tray above the action bar; the
Settings button toggles it, Esc or a click on empty page space closes it.
Whether selection opens the tray is the `studio.alpha.trayOnSelection`
user preference (on unless false), switched in the account menu.

"Keep open" docks the same fields as the Properties panel, the first
button of the rail's panels. While it is docked the tray no longer opens on
selection; the panel follows the selection and, with nothing selected,
shows the page - its title, URL path and menu visibility first, then its
inspector groups. Its header opens the path menu (parents, the node,
its children), as does the node button of the action bar.
